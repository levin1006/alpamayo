# Codex CLI 작업 지시서: Alpamayo-R1 논문 전체 한국어 번역

이 문서는 새 Codex CLI 세션의 AI가 직접 읽고 실행하기 위한 작업 지시서다.

## 작업 목표

아래 PDF 논문 전체를 한국어로 완전 번역하여 Markdown 파일로 생성한다.

```text
docs/Alpamayo-R1 Bridging Reasoning and Action Prediction for Generalizable Autonomous Driving in the Long Tail, NVIDIA Research.pdf
```

요약본을 만들지 말라. 원문 전체를 빠짐없이 번역하라.

## 작업 디렉터리

반드시 다음 디렉터리에서 작업하라.

```text
/home/user/Workspace/alpamayo
```

## 산출물

최종 산출물은 다음 두 경로에 생성한다.

```text
docs/Alpamayo-R1 Korean Translation.md
docs/alpamayo-r1-translation-assets/
```

- `docs/Alpamayo-R1 Korean Translation.md`: 논문 전체 한국어 번역 Markdown
- `docs/alpamayo-r1-translation-assets/`: PDF에서 추출한 그림/이미지 파일

## 사전 조건

이 PDF는 41쪽 논문이다. LaTeX 기반 PDF이며, 다음 도구 사용을 우선 고려한다.

```text
pdfinfo
pdftotext
pdfimages
pdftoppm
```

`pdftotext -layout`으로 텍스트를 추출하면 원문 구조를 비교적 잘 보존할 수 있다.

## 실행 원칙

- 빠르게 끝내기보다 누락 없는 완전성, 그림 링크 정확성, Markdown 구조 보존을 우선하라.
- 한 번에 전체를 처리하려 하지 말고, 섹션 단위로 추출, 번역, 조립, 검수하라.
- 컨텍스트가 부족하면 중단하지 말고 파일 기반 중간 산출물을 사용해 계속 진행하라.
- 임의 요약, 생략, 재구성, 해설 추가를 하지 말라.
- 커밋하지 말라.
- 불필요한 코드 변경을 하지 말라.
- 최종 산출물에 필요 없는 임시 파일은 정리하라.

## 번역 기준

- 제목, 저자/소속 표기, 초록, 본문, 섹션 제목, 각주, 표 캡션, 그림 캡션, 부록을 모두 번역하라.
- 원문의 논리 구조와 섹션 계층을 Markdown heading으로 보존하라.
- Figure, Table, Equation 번호는 원문 번호를 유지하라.
- 수식은 원문 형태를 유지하라.
- 변수명, 모델명, 데이터셋명, 방법론명, 논문명, 고유명사는 원문 표기를 유지하라.
- 필요한 경우 고유명사 뒤에 괄호로 짧은 한국어 설명을 덧붙일 수 있다.
- 참고문헌은 원문 표기를 기본 유지하라.
- 원문에 명백한 오탈자가 있어도 의미를 훼손하지 말고 번역하라.
- 필요한 경우 짧은 역주는 괄호 안에 표시하라.

## 그림 처리 기준

- PDF의 필요한 그림을 추출하여 `docs/alpamayo-r1-translation-assets/` 아래에 저장하라.
- Markdown에서는 상대 경로로 그림을 연결하라.
- 파일명은 읽기 쉽게 지정하라.
- 최종 Figure 이미지 파일은 반드시 Figure 본체 영역만 포함해야 한다.
- PDF 페이지 전체를 렌더링한 이미지를 최종 Figure 파일로 사용하지 말라.
- `pdftoppm` 등으로 페이지를 렌더링하는 것은 Figure 영역을 crop하기 위한 중간 단계로만 허용한다.
- 최종 PNG 안에 페이지 상단 제목, 본문 문단, 페이지 번호, 다른 섹션 텍스트, 넓은 페이지 여백이 들어가면 실패로 간주하라.
- 캡션은 이미지 안에 포함하지 말고 Markdown 본문에서 이미지 바로 아래에 한국어 텍스트로 배치하라.

예:

```markdown
![Figure 1. 시스템 개요](alpamayo-r1-translation-assets/figure-01.png)
```

- 먼저 `pdfimages` 또는 PDF 내 이미지 객체 추출로 Figure 본체를 온전하게 얻을 수 있는지 확인하라.
- raw image 추출만으로 Figure가 깨지거나 누락되거나 텍스트/벡터 요소가 빠지면, 해당 PDF 페이지를 고해상도로 렌더링한 뒤 Figure bounding box만 crop하라.
- Figure가 여러 subfigure/panel로 구성되어 있으면 전체 Figure 묶음 영역만 하나의 이미지로 crop하라. 패널을 임의로 쪼개지 말라.
- Figure 본체와 캡션이 시각적으로 가까워도, 가능한 한 Figure 본체만 crop하고 캡션은 제외하라.
- 그림 캡션은 Markdown에서 그림 바로 아래에 한국어로 번역하여 배치하라.
- 원문 그림 번호와 Markdown의 그림 번호가 대응되도록 하라.

Figure crop 검수 기준:

- 각 PNG에 A4 페이지 전체가 보이면 실패다.
- 각 PNG에 페이지 번호가 보이면 실패다.
- 각 PNG에 논문 본문 문단이 크게 포함되어 있으면 실패다.
- 각 PNG가 과도한 흰 여백을 포함하면 실패다.
- 각 PNG는 Figure 본체를 식별 가능한 해상도로 보여야 한다.
- Markdown에서 Figure 이미지 아래의 캡션은 정상적으로 남아 있어야 한다.

## 표 처리 기준

- 표는 가능하면 Markdown table로 재작성하라.
- 복잡한 표는 구조가 깨지지 않도록 원문 표 구조를 최대한 보존하라.
- 표 번호와 표 캡션을 원문과 대응되게 유지하라.
- 표 내부의 기술 용어, 모델명, 수치, 단위는 원문 의미를 보존하라.

## 권장 작업 절차

1. `pdfinfo`로 PDF 페이지 수와 메타데이터를 확인한다.
2. `pdftotext -layout`으로 전체 텍스트를 추출한다.
3. 추출 텍스트를 섹션 단위로 나눈다.
4. 각 섹션을 한국어로 번역한다.
5. `pdfimages`, `pdftoppm` 등으로 필요한 그림을 추출한다. 단, `pdftoppm`으로 만든 페이지 전체 이미지는 최종 산출물로 쓰지 말고 반드시 Figure 영역만 crop한다.
6. Markdown 본문에 번역문, 표, 그림 링크, 캡션을 조립한다.
7. 최종 검수를 수행한다.

## 최종 검수 체크리스트

완료 전에 반드시 다음 항목을 확인하라.

- `docs/Alpamayo-R1 Korean Translation.md` 파일이 존재하는가
- `docs/alpamayo-r1-translation-assets/` 폴더가 존재하는가
- 주요 섹션과 부록이 모두 포함되었는가
- 초록부터 참고문헌/부록까지 원문 흐름이 보존되었는가
- 번역되지 않은 긴 영어 문단이 남아 있지 않은가
- Figure/Table/Equation 번호가 원문과 대응되는가
- Markdown 그림 링크가 실제 파일을 가리키는가
- 각 Figure PNG가 페이지 전체 렌더링이 아니라 Figure 본체만 crop한 이미지인가
- 각 Figure PNG에 페이지 번호, 본문 문단, 큰 페이지 여백이 들어가지 않았는가
- 그림 캡션이 그림 바로 아래에 배치되었는가
- Markdown heading 구조가 깨지지 않았는가
- 임시 파일이 최종 산출물 주변에 불필요하게 남아 있지 않은가

## 기존 산출물의 Figure 문제 수정 지시

이미 번역 Markdown이 생성되었지만 Figure 이미지가 PDF 페이지 전체 렌더링으로 저장된 경우, 다음 지시를 수행하라.

```text
기존 번역 Markdown은 유지하되, Figure 이미지 산출물을 다시 생성하라.

현재 문제:
`docs/alpamayo-r1-translation-assets/figure-01.png` ~ `figure-14.png`가 Figure 자체가 아니라 PDF 페이지 전체 렌더링 이미지다. Markdown에서 보면 페이지 안에 논문 페이지가 다시 들어간 형태라 부적절하다.

목표:
각 Figure 이미지를 “논문 페이지 전체”가 아니라 “Figure 본체 영역만” 보이도록 다시 추출/생성하라.

엄격한 요구사항:
- full-page render 이미지를 최종 Figure 파일로 사용하지 말라.
- 각 Figure 파일은 해당 Figure의 본체 도식/이미지 영역만 포함해야 한다.
- 페이지 상단 제목, 본문 문단, 페이지 번호, 여백, 다른 섹션 텍스트가 Figure 이미지 안에 들어가면 안 된다.
- Figure caption은 이미지에 포함하지 말고 Markdown에서 이미지 바로 아래에 한국어 텍스트로 유지하라.
- raw `pdfimages` 추출만으로 Figure가 온전하지 않으면, PDF 페이지를 고해상도로 렌더링한 뒤 Figure bounding box만 crop하라.
- `pdftoppm`으로 만든 페이지 전체 이미지를 그대로 `figure-XX.png`로 저장하는 것은 금지한다. `pdftoppm`은 중간 렌더링 용도로만 사용할 수 있으며, 최종 산출물은 반드시 Figure bounding box로 crop된 이미지여야 한다.
- Figure가 여러 subfigure/panel로 구성되어 있으면 전체 Figure 묶음 영역만 crop하라. 각 패널을 따로 쪼개지 말라.
- 기존 Markdown의 Figure 링크 경로는 유지하되, 연결된 PNG 파일 내용을 올바른 crop 이미지로 교체하라.

권장 구현 방식:
1. `docs/Alpamayo-R1 Korean Translation.md`에서 Figure 1-14의 순서와 캡션을 확인한다.
2. PDF 원문에서 각 Figure가 위치한 페이지를 확인한다.
3. 각 Figure 페이지를 임시로 고해상도 렌더링한다.
4. PyMuPDF, Pillow, ImageMagick, 또는 사용 가능한 도구로 Figure 영역의 bounding box만 crop한다.
5. crop 결과를 기존 `docs/alpamayo-r1-translation-assets/figure-XX.png` 경로에 덮어쓴다.
6. Markdown 링크는 기존 상대 경로를 유지한다.
7. 최종 검수에서 각 Figure PNG가 페이지 전체 렌더링이 아닌지 확인한다.

검수 기준:
- 각 PNG에 A4 페이지 전체가 보이면 실패다.
- 각 PNG에 페이지 번호가 보이면 실패다.
- 각 PNG에 논문 본문 문단이 크게 포함되어 있으면 실패다.
- 각 PNG가 과도한 흰 여백을 포함하면 실패다.
- 각 PNG는 Figure 본체를 식별 가능한 해상도로 보여야 한다.
- Markdown에서 Figure 이미지 아래의 캡션은 정상적으로 남아 있어야 한다.

작업 범위:
- 번역문 전체를 다시 번역하지 말라.
- Figure 이미지 파일과 필요한 경우 Markdown의 Figure 링크/캡션 주변만 수정하라.
- 커밋하지 말라.
```
